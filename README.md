# 🚢 Battleship Game – JavaScript Web Application  

This repository contains a simple, interactive Battleship game built with JavaScript, HTML, and CSS. The game runs directly in the browser, allowing users to guess ship locations on a grid and sink the battleship through strategic moves.  

## ⚙️ Code Features:-  
🔹 Randomly generates ship positions within a 0–6 grid.  

🔹 Accepts user input through prompts and validates entries.  

🔹 Provides instant feedback:  
  - “HIT!” when the guess matches a ship location.  
  - “MISS!” when the guess is incorrect.  
  - “You sank my battleship!” when all ship parts are hit.  

🔹 Tracks the number of guesses and calculates shooting accuracy at the end.  

🔹 Engaging alerts for smooth user interaction.  

## 💻 Technologies Used  

• JavaScript  
• HTML  
• CSS  

## 📊 Game Flow  

1. A battleship of length 3 is hidden randomly in a grid (0–6).  
2. Player enters guesses via prompt.  
3. Hits and misses are tracked until the ship is sunk.  
4. Final stats show total guesses and accuracy percentage.
